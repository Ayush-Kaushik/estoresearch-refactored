# View Product Catalog Metadata

## Goal

Allow the operator to view product catalog metadata, including the total number 
of products and the number of products by type.

## Required Behaviour

### View Metadata Flow

- Selecting "View Metadata" from the main menu displays the product catalog metadata.
- The metadata includes:
    - Total number of products in the catalog.
    - Number of products by type (e.g., books, electronics).
- If no products are present in the catalog, display a message indicating that the catalog is empty.
